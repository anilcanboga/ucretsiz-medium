# UcretsizMedium

UcretsizMedium Chrome extension, [Freedium](https://github.com/Freedium-cfd) sayesinde paywall’u bypass ederek Medium makalelerini ücretsiz okumanızı sağlar. Medium makalelerine bir buton ekler ve abonelik olmadan tam içeriğe erişmenize olanak tanır.

## Installation

UcretsizMedium Chrome extension’ı aşağıdaki adımları takip ederek kurabilirsiniz:

1. Extension dosyalarını GitHub repository’sinden indirin.

2. Google Chrome’u açın ve sağ üst köşedeki üç nokta menüsüne tıklayıp **"More tools" > "Extensions"** yolunu izleyerek Extensions sayfasına gidin.

3. Sağ üst köşedeki switch’i kullanarak **Developer mode**’u etkinleştirin.

4. **"Load unpacked"** butonuna tıklayın ve **`extension` klasörünü seçin**.

5. UcretsizMedium extension artık yüklenmiş olacak ve yüklü extension’lar listesinde görünecektir.

## Usage

UcretsizMedium extension’ı kullanmak için:

1. Paywall arkasında olan herhangi bir Medium makalesine gidin.

2. Sayfanın sağ alt köşesine extension tarafından eklenen **"Ücretsiz Oku"** butonuna tıklayın.

3. Makalenin tam içeriğini herhangi bir kısıtlama olmadan okuyun.
